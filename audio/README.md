# Voice lessons

Daily teaching audio is generated in the Grok teaching thread (Voice, Altair).

This folder is reserved for published MP3s.

**Current limit:** the GitHub connector commits **text**. Lesson 0 audio is about 5.7 MB. It lives in the teaching workspace at `artifacts/UPER-course/audio/` until a binary-safe publish path (git + LFS, or a release asset) is wired.

When an MP3 is published here, name it:

```
YYYY-MM-DD-lesson-NN-short-slug.mp3
```

Example: `2026-09-13-lesson-00-orientation.mp3`
