# Problem Fluency Rubric

Score **how well they understand** a problem, and **how well they could or did solve it**.

Use 0 / 1 / 2. Leave blank if not observable. Do not score character.

## Understand — how well they understand the problem

| Item | 2 looks like |
|------|----------------|
| Problem statement | One or two sentences. Not a slogan. Not the fix. |
| Facts vs interpretations | Observables with source and time, separate from hypotheses |
| Success criteria | Testable. Not “make it go away.” |
| Out of scope | Said aloud for this cycle |
| Known unknowns | Listed with a way to learn them |
| Owner | A named person — not a team or function |
| Control buckets | Control / influence / cannot-control where it is sticky |

## Plan — how well they could solve it

| Item | 2 looks like |
|------|----------------|
| Two approaches | Including a rejected-why |
| Named step owners | Humans, not “the team” or “IMO” |
| Stop condition | Plus at least one go / no-go gate |
| External dependencies | Named as influence or cannot-control |
| Reference class | Range, not fake precision |
| Closing steps | Verify, document, communicate exist on the plan |

## Execute — how well they are solving / did solve (process)

| Item | 2 looks like |
|------|----------------|
| Outcome evidence | The world changed, not only the calendar |
| Deviations | Conscious, logged, approved |
| Last mile | Boring steps still staffed |
| Close state | Plan followed or formally stopped — not ghosted |

## Review — whether learning will stick

| Item | 2 looks like |
|------|----------------|
| Outcomes vs criteria | Compared, with evidence |
| Then vs now | Hindsight separated from the information available at the time |
| Owned action | A person and a date, or explicit “no change needed” |
| No character attacks | Decisions and conditions only |

## Stage hygiene

| Item | 2 looks like |
|------|----------------|
| Named stage | They can say which stage they are in |
| No silent skip | Exceptions are conscious and owned |
| Escalation | Used when ownership or appetite is missing |

## Scoring

Fluency % = points / (items scored × 2).

| Band | Range |
|------|--------|
| Theatre / unframed | 0–39% |
| Partial / heroics | 40–59% |
| Competent framing | 60–74% |
| Disciplined | 75–89% |
| Facilitator-grade | 90–100% |

Report three sub-scores when you can: **Understand %**, **Could-solve %** (Plan + Execute), **Review + hygiene %**.
